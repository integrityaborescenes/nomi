<p align="center">
  Генератор имён компонентов из фразы — на русском или английском.<br/>
  Локально, без интернета, в одном окне.
</p>

## Использование

1. Введи фразу.
2. Submit или Enter.
3. Выбери стиль вывода: **Pascal** / **camel** / **kebab** / **snake**.
4. ↻ — другой вариант, ⧉ или клик по имени — скопировать.

**Хоткеи:**
- `Ctrl + N` — показать/скрыть окно (работает глобально, пока приложение запущено)
- <img src="public/icons/pinIco.svg" width="14" align="absmiddle" alt="pin"/> в titlebar — закрепить окно поверх всех остальных

## Пример работы

```
"Шапка пользовательской панели"       →  UserDashboardHeader
"Карточка товара со скидкой"          →  DiscountProductCard
"Кнопка восстановления пароля"        →  PasswordRecoveryButton
"login form with captcha"             →  LoginFormCaptcha
"Видеоплеер с субтитрами и скоростью" →  VideoPlayerSubtitlesSpeed
```
